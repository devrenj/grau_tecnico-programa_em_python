## Sobre o Projeto

Este programa utilizou bibliotecas nativas do Python, sendo elas:

- TKinter
- SQLite3

Não sendo portanto necessária a instalação de recursos adicionais.

## Objetivo

- Automatizar o processo de cadastro de trabalhos e provas, possibilitando facilidade na correção através da utilização de gabarito.
- Mostrar as notas tanto da turma quanto de cada aluno individualmente.
